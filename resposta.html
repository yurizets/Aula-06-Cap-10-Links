Introducão ao MVC

O padrão MVC(Model Viewer Controler) é uma arquitetura de software utilizadano desenvolvimento de aplicações para separar a lógica de negócios, a interface do usuário e o controle de dados

Componentes do MVC

    • Model(Modelo) - Representa os dados e a lògica de negócio da aplicação
      View(Visão) - Responsável pela interface com usuário e exibição dos dados
      Controler(Controlador) - Intermedia a comunicação ente o Model e a View
